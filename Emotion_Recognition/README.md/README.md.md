# Emotion Recognition from Speech

This project focuses on identifying human emotions from spoken audio using deep learning.

### Goal
Classify speech audio into emotions such as:
- Happy
- Sad
- Angry
- Neutral
- Fearful
- Disgust
- Calm
- Surprised

### Dataset
Audio samples labeled with emotions and a CSV file linking file names to labels.

### Approach
1. Extract audio features (e.g., MFCCs)
2. Train deep learning model (e.g., MLP, CNN, RNN)
3. Evaluate emotion classification accuracy

Ideal for applications in human-computer interaction, virtual assistants, and mental health analysis.
